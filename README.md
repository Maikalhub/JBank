## Important 🚨

### 1) Project Type
This project is a **client-server application** with a modular architecture.  
The backend handles all business logic, security, and database operations.  
The frontend communicates with the backend via REST API.

### 2) Backend
The backend is implemented in **Java 17** using Spring Boot.  
It handles authentication, transaction processing, and database management.

### 3) Frontend
The frontend was developed with **JavaBuilder** (latest version) for building the UI and client interaction.

### 4) Correct Launch
To run the application correctly:  
1. Make sure **MS SQL Server 2022** is installed and running.  
2. Locate the folder with SQL files for **database creation**.  
3. Execute the SQL scripts to generate the database schema and initial data.  
4. After that, start the backend and frontend applications to test full functionality.
